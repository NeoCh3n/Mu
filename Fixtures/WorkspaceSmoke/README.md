# Mu Workspace Smoke Fixture

This small Git repository is used for the macOS workbench acceptance task.

The expected flow is:

1. create a Task for **Forge** through **Synthetic Runtime A**;
2. open this file from **Files** and **Browser**;
3. add a durable note in **Chat**;
4. run `git status` from **Terminal snapshots**;
5. capture a Checkpoint and inspect it in **Artifacts**.

No network access or vendor account is required.
